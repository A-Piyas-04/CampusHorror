======================================================================
1. CORE OBJECTIVE
======================================================================

Create the first real, manually editable campus blockout for the Main Gate area.

The blockout must establish:

- recognizable real-world spatial relationships,
- correct major landmarks,
- useful walking space,
- an editable modular scene structure,
- the first real building entrance / interior transition,
- a foundation that can later receive polished 2.5D artwork without rebuilding
  the gameplay architecture.

The game remains technically 2D.

However, the intended final presentation is NOT flat diagram-like 2D.

The planned visual direction is:

- 2D gameplay and physics,
- slightly angled top-down presentation,
- faux-3D / 2.5D-looking assets,
- visible building and wall height,
- volumetric-looking trees and props,
- stylized shadows and depth,
- recognizable real campus architecture,
- red-brick institutional architecture as an important visual identity.

Do not implement final polished art in this task.

9. EDITABILITY IS A HARD REQUIREMENT
======================================================================

The user must be able to manually customize this map later inside Godot.

Therefore:

DO:
- use separate nodes / reusable scenes,
- use editable positions/sizes,
- use modular props,
- expose useful Inspector parameters,
- organize related map elements under clearly named parents,
- keep paths, fields, courts, building masses and vegetation separable,
- use scene instances for reusable objects where appropriate.

DO NOT:
- bake the whole map into a single image,
- bake all collision into one opaque object,
- hard-code large amounts of map geometry in scripts unnecessarily,
- generate one giant procedural map that is difficult to edit,
- hide important layout values inside code.

A user should be able to open the zone in Godot and visually:
- move a tree,
- reposition a wall,
- resize part of a path,
- shift the CDS footprint,
- adjust the field boundary,
- move a court,
- change an entrance,
without rewriting gameplay systems.
