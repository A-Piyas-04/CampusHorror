# Game idea and goals

## Confirmed user idea

Create a custom **2D top-down game using Godot**. Its world represents a university campus known personally to the user. The campus layout and recognizable structures should be custom rather than an unrelated map assembled from random asset packs.

Planned environments include:

- Campus outdoor areas and fields.
- Buildings, hallways and rooms.
- Underground areas.
- Underwater areas.
- A small hospital.
- Multiple scenes or connected areas.

The user has mentioned day/night environments, enemies, puzzles, a lantern system and mystery. Their exact behavior, narrative purpose and balance have not been specified.

## Immediate goal

Prepare the development environment and a basic reusable blueprint before designing the detailed story or mechanics. The user wants to describe future content and have the AI help implement it within an established structure.

## Long-term goal

Build a recognizable campus game whose environments and mechanics share a consistent visual style and technical foundation. The user's contribution centers on ideas, campus knowledge, layout, drag-and-drop placement, visual decisions and testing.

## Proposed first playable scope

One small outdoor area, one player, one custom building, one entrance and one interior room. Use placeholders first, then replace them with a coherent custom asset sample.

This is a proposed prototype scope, not a reduction of the long-term vision.

## Not yet defined

Game title, university name, protagonist, plot, chapters, win condition, combat rules, enemy types, puzzle types, lantern behavior, underwater controls and target release platform.

Do not infer the campus is a particular university from unrelated profile information. Do not import characters or mechanics from the user's previous game ideas unless explicitly requested.
